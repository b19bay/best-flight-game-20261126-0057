MERIDIAN RUN: fly the alpine courier route — 8 rings, 3 missions, 1 mountain strip. A complete offline flight game in vanilla JavaScript and canvas: golden-hour valley, seeded terrain, throttle-and-turn flight model with stalls, fuel and damage, three missions (Ring Run, Courier, Supply Drop), a cockpit view with lit instruments, and synthesized engine sound. No network, no build step, no assets — every pixel and sound is generated by the game's own code.

## Run it

```sh
cd game && python3 -m http.server 8080
```

Open http://localhost:8080 in a desktop browser. Arrows / WASD fly, Shift / Ctrl throttle, mouse steers gently, C toggles the cockpit view, 1 / 2 / 3 pick a mission, P pauses, R restarts, M mutes.
